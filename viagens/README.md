# Agência de Viagens

Aplicação web para catálogo de destinos de viagens, construída com React, TypeScript e Vite.

## Como iniciar o projeto

Para instalar as dependências e rodar em ambiente de desenvolvimento:
```bash
npm install
npm run dev
```

Para rodar os testes:
```bash
npm run test
```

Para fazer o build de produção:
```bash
npm run build
```
