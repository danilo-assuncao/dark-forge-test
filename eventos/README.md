# Eventos

Aplicação de eventos construída com Vite, React, TypeScript Strict e Vitest.

## Comandos

- `npm run dev`: Inicia o servidor de desenvolvimento
- `npm run build`: Compila o projeto (com verificação de tipos)
- `npm test`: Roda os testes com Vitest
- `npm run lint`: Roda o linter (oxlint)
